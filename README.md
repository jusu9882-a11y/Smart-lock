# VANTA — Smart-lock

**Codename:** VOID  
A personal Android cyber-lock experience: OLED black, electric cyan, minimal sci-fi Core, and carefully layered authentication.

> Security note: this repository begins as an app prototype. A custom screen or overlay is not a replacement for Android's secure system lock screen. The app must never claim device-level protection until implemented through supported Android security mechanisms and tested.

## Design
- OLED-black surfaces and electric-cyan accents
- Core unlock animation concept
- Rotary cipher / gesture as an interaction layer (not sole security)
- Android system credential authentication planned
- Offline-first, no ads, no telemetry by default
